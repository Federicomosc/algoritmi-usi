Testo completo dell'esercizio (PDF) 
Write an algorithm Max-Heap-Delete(H, i) that, given a max-heap H and an (30’)
index i, deletes the i-th element in H. The heap is stored in an array H, and by “ i-th element” we
refer to the element in H[i]. You may access the heap size of H as H. heap-size. The complexity
of max-Heap-Delete must be O(log n), where n is the size of the heap. You must detail every
algorithm you use.
Soluzione ufficiale (PDF Carzaniga) 
A deletion of an element in position i is conceptually identical to a deletion of the root element.
Therefore, the idea is the same as the classic Heap-Extract-Max algorithm: we move the last
element into position i and reduce the heap size by one. At this point, we proceed with a max-
heapify from position i.
Max-Heap-Delete(H, i)
1 H[i] = H[H. heap-size]
2 H. heap-size = H. heap-size − 1
3 if i > H. heap-size
4 return
5 if i > 1 and H[i] > H[ ⌊i/2⌋]
6 while true
7 swap H[i] ↔ H[⌊i/2⌋]
8 i = H[⌊i/2⌋]
9 if i ≤ 1 or H[i] ≤ H[⌊i/2⌋]
10 return
11 else while true
12 m = i
13 if 2i ≤ H. heap-size
14 if H[m] < H[ 2i]
15 m = 2i
16 if 2i + 1 ≤ H. heap-size and H[m] < H[ 2i + 1]
17 m = 2i + 1

19 return
20 swap H[i] ↔ H[m]
21 i = m
