# Algoritmi & Strutture Dati — USI

Appunti interattivi per il corso di **Algoritmi & Strutture Dati** (Prof. Antonio Carzaniga, USI).

## Contenuto

- **14 capitoli** HTML con spiegazioni, simulatori e quiz
- **Guida allo studio** (`guida-studio.html`)
- **Final 2021–2025** con soluzioni passo-passo (`final/`)
- **PDF** originali del corso nelle cartelle tematiche

## Come usarlo

Apri [`index.html`](index.html) nel browser — funziona anche su telefono (menu ☰ in alto a sinistra).

### GitHub Pages

Se abiliti Pages su questo repo (Settings → Pages → branch `main`, cartella `/ (root)`), l'app sarà online su:

`https://<tuo-username>.github.io/<nome-repo>/`

## Struttura

| Cartella | Argomento |
|----------|-----------|
| `01 - Complessita` | Analisi e teoria della complessità |
| `02 - Strutture dati` | Liste, stack, hash tables |
| `03 - Ordinamento` | Insertion, merge, quick, heap sort |
| `04 - Alberi` | BST, red-black, B-tree |
| `05 - Grafi` | BFS, MST, Dijkstra |
| `06 - Tecniche algoritmiche` | Greedy, programmazione dinamica |
| `final/` | Esami finali 2021–2025 |
